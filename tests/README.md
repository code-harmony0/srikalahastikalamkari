## Legend
- ⭐ = Critical Path Test Case
- 🔄 = Regression Test Case
- ⚡ = Smoke Test Case

## Naming Convention
`TC-[CATEGORY]-[NUMBER]: [Brief Description]`

## Priority Levels
- **P0 (Critical)**: Core functionality, must pass before release
- **P1 (High)**: Important features, should pass before release  
- **P2 (Medium)**: Nice to have, can be fixed post-release
- **P3 (Low)**: Minor features, low impact if broken
